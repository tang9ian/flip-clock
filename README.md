# Flip Clock

[English](#english) | [中文](#中文)

---

## English

A flip clock application built with Svelte + TypeScript.

### Features

- 🎯 Smooth flip animation
- 🎨 Modern UI design
- ⚡ Lightweight and performant
- 📱 Responsive layout

### Tech Stack

- Svelte
- TypeScript
- Vite
- CSS3 Animations

### Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Project Structure

```
flip-clock/
├── src/
│   ├── lib/
│   │   └── FlipUnit.svelte    # Flip unit component
│   ├── App.svelte              # Main app component
│   ├── app.css                 # Global styles
│   └── main.ts                 # Entry point
├── public/                     # Static assets
└── index.html                  # HTML template
```
